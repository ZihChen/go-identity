# DIP違反修復計劃 - Tracing抽象化重構

**日期**: 2025-10-21  
**重構類型**: Dependency Inversion Principle (DIP) 違反修復  
**影響範圍**: Use Case層的Tracing依賴

## 🎯 重構目標

修復Fat Identity Cat專案中Use Case層直接依賴Infrastructure層具體實現的DIP違反問題，將tracing功能抽象化為interface，遵循Clean Architecture原則。

## 🔍 問題分析

### 當前DIP違反
**位置**: `internal/application/usecase/merchant/merchant_usecase.go:15`
```go
import "github.com/jvdiamondtech/ms-identity-cat/internal/infrastructure/tracing"
```

**問題描述**:
- Application層直接依賴Infrastructure層具體實現
- 違反Clean Architecture的依賴方向規則
- 難以進行單元測試
- 增加模組間耦合度

### 影響文件列表
1. `internal/application/usecase/merchant/merchant_usecase.go`
2. `internal/application/usecase/player/player_usecase.go`

## 📋 重構計劃

### Phase 1: 創建Tracing Interface (參考Fat-Notification-Cat)

#### 1.1 創建Domain層Tracing Interface
**文件**: `internal/domain/ports/outbound/infrastructure/tracing.go`

參考: `/Users/winstonlin/go/src/fatcat/fat-notification-cat/internal/domain/ports/outbound/infrastructure/tracing.go`

**需要實現的interface方法**:
```go
type TracingService interface {
    StartSpan(ctx context.Context, spanName string, opts ...trace.SpanStartOption) (context.Context, trace.Span)
    RecordSpanError(span trace.Span, err error)
    RecordSpanAttributes(span trace.Span, attrs ...attribute.KeyValue)
    TraceEvent(span trace.Span, name string, attrs ...attribute.KeyValue)
    SpanEnd(span trace.Span)
    GetTraceparent(ctx context.Context) string
    InjectTraceparentToJSON(ctx context.Context, data []byte) ([]byte, error)
    RecordSpanStatus(span trace.Span, code codes.Code, desc string)
}
```

#### 1.2 更新Infrastructure層實現
**文件**: `internal/infrastructure/tracing/tracing.go`

確保現有的tracing實現符合新的interface定義，並實現所有必要的方法。

### Phase 2: 重構Use Case層

#### 2.1 更新Use Case Constructor
修改所有Use Case的constructor，加入TracingService依賴注入：

**修改文件**:
- `internal/application/usecase/merchant/merchant_usecase.go`
- `internal/application/usecase/player/player_usecase.go`
- `internal/application/usecase/manager/manager_usecase.go`
- `internal/application/usecase/level/level_usecase.go`
- `internal/application/usecase/tag/tag_usecase.go`

**修改範例**:
```go
// Before
import "github.com/jvdiamondtech/ms-identity-cat/internal/infrastructure/tracing"

// After  
import "github.com/jvdiamondtech/ms-identity-cat/internal/domain/ports/outbound/infrastructure"

type MerchantUseCase struct {
    merchantRepo  repository.MerchantRepository
    eventProducer service.EventProducer
    logger        infrastructure.Logger
    tracing       infrastructure.TracingService  // 新增
}
```

#### 2.2 更新Tracing方法調用
將所有直接調用tracing包方法的地方改為使用注入的interface：

**修改範例**:
```go
// Before
ctx, span := tracing.StartSpan(ctx, "MerchantUseCase.SyncMerchant")
defer tracing.SpanEnd(span)

// After
ctx, span := u.tracing.StartSpan(ctx, "MerchantUseCase.SyncMerchant")
defer u.tracing.SpanEnd(span)
```
