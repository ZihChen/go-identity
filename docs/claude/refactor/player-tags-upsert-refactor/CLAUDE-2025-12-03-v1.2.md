- **錯誤類型**: MySQL Deadlock (Error 1213 - 40001)
- **位置**: `internal/adapter/inbound/handler/worker/worker_handler.go:157`
- **根本原因**: 複雜的 upsert 操作導致多重索引衝突

### 🔍 現有重試機制分析
**關鍵發現**: TagUseCase 已有 Redis 分散式鎖 retry (`tag_usecase.go:282`)，但這個 retry **只處理鎖獲取失敗，無法處理 MySQL deadlock**

**現有 Retry 範圍**:
```go
// tag_usecase.go:115 - 只 retry Redis lock acquisition

    err = u.playerTagRepo.BatchUpdate(ctx, player.GetID(), tagIDs)  // ← MySQL deadlock 發生在這裡
    // ... Redis retry 無法捕獲此 deadlock

```

**問題核心**: MySQL deadlock 發生在 `fn()` 執行內部，Redis 鎖 retry 邏輯無法處理

### Deadlock 錯誤模式
```sql
Error 1213 (40001): Deadlock found when trying to get lock; try restarting transaction
```

## 技術根本原因分析

### 資料庫鎖衝突點

**Players 表索引結構**:
```sql
-- 主要衝突索引
PRIMARY KEY (id)
UNIQUE INDEX idx_players_global_player_id (global_player_id)  ← 主要衝突點
UNIQUE INDEX idx_players_api_key (api_key)
INDEX idx_players_merchant_id (merchant_id)
INDEX idx_players_level_id (level_id)
INDEX idx_players_deleted_at (deleted_at)
```

**鎖競爭模式**:
1. **Gap Lock**: `global_player_id` 唯一索引的間隙鎖定
2. **Next-Key Lock**: 範圍鎖影響相鄰記錄
3. **Insert Intention Lock**: 新插入記錄時的意向鎖衝突
4. **複雜 UPDATE**: 多重條件更新延長鎖定時間

### 當前同步流程

**同步流程** (`player_usecase.go:53-144`):
```
1. FindByGlobalID(merchant) → 共享鎖
2. findOrCreateLevel() → 潛在寫鎖
3. Player entity creation → 記憶體操作
4. playerRepo.Upsert() → 複雜寫鎖 + 索引鎖
5. eventProducer.PublishPlayerSync() → 外部調用
```

**關鍵區段**: 步驟 2-4 同時持有資料庫鎖

## 簡化實作策略

### 🎯 核心解決方案: 雙層 Retry 機制

**現有問題**: 
- ✅ Redis 分散式鎖 retry (已存在) - 處理鎖競爭
- ❌ **MySQL deadlock retry (缺失)** - 處理資料庫死鎖

**解決方案**: 在關鍵 MySQL 操作中加入 deadlock retry

```go
// 新增到 tag_usecase.go 檔案末尾
func (u *TagUseCase) batchUpdateWithRetry(ctx context.Context, span trace.Span, playerID uint64, tagIDs []uint64) error {
    maxRetries := 3
    baseDelay := 100 * time.Millisecond

    for attempt := 0; attempt <= maxRetries; attempt++ {
        err := u.playerTagRepo.BatchUpdate(ctx, playerID, tagIDs)
        
        if err == nil {
            u.logger.InfoWithContext(ctx, "Batch upsert player tags completed",
                u.logger.UInt64("player_id", playerID),
                u.logger.Int("count", len(tagIDs)),
                u.logger.Any("tag_ids", tagIDs))
            return nil
        }
        
        if u.isDeadlockError(err) && attempt < maxRetries {
            delay := baseDelay * time.Duration(1<<uint(attempt)) // 100ms, 200ms, 400ms
            u.logger.WarnWithContext(ctx, "MySQL deadlock detected, retrying",
                u.logger.UInt64("player_id", playerID),
                u.logger.Int("attempt", attempt+1),
                u.logger.Duration("delay", delay),
                u.logger.Error("error", err))
            
            time.Sleep(delay)
            continue
        }
        
        u.tracing.RecordSpanError(span, err)
        return fmt.Errorf("batch update player tags failed: %w", err)
    }
    
    return fmt.Errorf("batch update failed after %d retries", maxRetries)
}

func (u *TagUseCase) isDeadlockError(err error) bool {
    if err == nil {
        return false
    }
    errorStr := err.Error()
    return strings.Contains(errorStr, "Deadlock found") ||
           strings.Contains(errorStr, "1213") ||
           strings.Contains(errorStr, "40001")
}
```

```go
// 新增到 player_usecase.go 檔案末尾
func (u *PlayerUseCase) upsertPlayerWithRetry(ctx context.Context, span trace.Span, player *entity.Player) error {
    maxRetries := 3
    baseDelay := 100 * time.Millisecond

    for attempt := 0; attempt <= maxRetries; attempt++ {
        err := u.playerRepo.Upsert(ctx, player)
        
        if err == nil {
            u.logger.InfoLog("Player upserted successfully",
                u.logger.String("global_id", player.GetGlobalPlayerID()),
                u.logger.String("account", player.GetAccount()))
            return nil
        }
        
        if u.isDeadlockError(err) && attempt < maxRetries {
            delay := baseDelay * time.Duration(1<<uint(attempt))
            u.logger.WarnLog("Player upsert deadlock detected, retrying",
                u.logger.String("global_id", player.GetGlobalPlayerID()),
                u.logger.Int("attempt", attempt+1),
                u.logger.Duration("delay", delay),
                u.logger.Error("error", err))
            
            time.Sleep(delay)
            continue
        }
        
        return err
    }
    
    return fmt.Errorf("player upsert failed after %d retries", maxRetries)
}

func (u *PlayerUseCase) isDeadlockError(err error) bool {

        return false
    }
    errorStr := err.Error()

           strings.Contains(errorStr, "40001")
}
```
