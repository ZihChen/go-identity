## 🚨 當前優先問題

### 🔴 Critical - 立即修復 (1-2 週內)

#### 1. 缺乏身份認證中間件 ⭐ **最高優先級**
- **狀態**: 🔄 **待處理**
- **問題**: API端點完全缺乏認證保護機制
- **位置**: internal/adapter/inbound/middleware/ (缺少auth_middleware.go)
- **風險**: 
  - 任何人都可存取所有API端點
  - 商戶資料完全暴露
  - 身份資料可被任意存取和修改
- **修復建議**:
  - 實作API Key認證中間件
  - 新增merchant隔離機制
  - 實作request rate limiting
  - 新增JWT token支援

#### 2. DSN密碼明文洩漏
- **狀態**: ✅ **已修復** (2025-10-08)
- **問題**: 資料庫DSN包含明文密碼在日誌中洩漏
- **位置**: internal/infrastructure/database/mysql/mysql.go:51-53
- **修復內容**:
  - ✅ 實作 `sanitizeDSN()` 函數進行密碼遮蔽
  - ✅ 更新日誌輸出使用sanitized DSN (密碼顯示為 `****`)
  - ✅ 新增正則表達式處理確保安全性
  - ✅ 保留必要連接資訊 (用戶名、主機、端口、資料庫名)
- **測試驗證**: ✅ 密碼成功遮蔽，程式碼編譯通過，不影響實際連接功能

#### 3. API Key明文儲存
- **狀態**: 🔄 **待處理**
- **問題**: Merchant和Player API Key以明文形式儲存
- **位置**: 
  - internal/infrastructure/models/merchant.go:11
  - internal/infrastructure/models/player.go:10
- **風險**: API Key洩漏時無法提供額外保護
- **修復建議**:
  - 實作API Key雜湊儲存
  - 新增salt機制
  - 考慮bcrypt或類似強化演算法
