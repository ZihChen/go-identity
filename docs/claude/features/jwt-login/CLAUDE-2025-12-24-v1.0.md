# JWT登入API

## 完成狀態

## 功能概述
新增一個玩家取得JWT token的登入API

## 技術實作
- 新增一個API接口 api/v1/players/login
  - Header：API-Key
  - Body
    - player_global_id
    - account
  - API實作邏輯
    - JWT Encoder
      - Header: Algorithm & Token Type：
      ```
      {
        "alg": "HS256",
        "typ": "JWT"
      }
      ```
    - Payload: Data：
      ```
      {
        "iss": "REDACTED_JWT_ISSUER",
        "sub": "player",
        "account": "winston883",
        "player_global_id": "FATCAT-PLAYER-883",
        "exp": 1766634602
      }
      ```
      - iss為jwt key
      - sub為player
      - exp為token過期時間戳(一小時過期)
    - Sign JWT: Secret
      ```
      REDACTED_JWT_SECRET
      ```
    - API Response：
