# gRPC Service Implementation Guide

**Feature**: gRPC Internal Microservice Communication  
**Date**: 2025-11-24  
**Version**: v1.0  
**Status**: Planning Phase  

## Overview

This document provides comprehensive implementation details for adding gRPC service capabilities to Fat Identity Cat for internal microservice communication with mTLS authentication and JWT token management.

## Architecture Design

### Service Architecture Strategy

Based on current project analysis, we recommend **Independent gRPC Service Pod** architecture:

```
Current Architecture:
- cmd/web (HTTP API) - External client communication
- cmd/consumer (KDS Processing) - Event streaming
- cmd/worker (Background Tasks) - Async processing  
- cmd/grpc (NEW) - Internal microservice communication
```

### Why Independent gRPC Pod?

#### Advantages

1. **Separation of Concerns**
   - Web Service: External HTTP API for frontend/third-party
   - gRPC Service: Internal microservice communication
   - Different protocols, middleware, security policies

2. **Scalability Benefits**
   - Independent scaling based on different traffic patterns
   - Resource optimization per service type
   - Avoid HTTP traffic impact on gRPC performance

3. **Deployment Flexibility**
   - Independent deployment and updates
   - Different resource configuration requirements
   - Separate health checks and monitoring

4. **Security Boundaries**
   - gRPC service deployed on internal network
   - Different network policies and firewall rules
   - mTLS configuration separated from HTTP API

### Hybrid Authentication Architecture

```
Client → Identity Service (REST/JWT) → Notification Service (gRPC/mTLS)
           |                                         ^
    Certificate Authority                    Service Registry
```

#### Two-Layer Authentication Strategy

1. **External Client Authentication** (JWT)
   - Client → Identity Service authentication
   - JWT token generation and validation
   - User-level authorization control

2. **Service-to-Service Authentication** (mTLS)
   - gRPC inter-service communication
   - Certificate-based authentication
   - Transport layer security

### Phase 3: gRPC Server Implementation

#### Main gRPC Service Command

```go
// cmd/grpc/grpc.go
package grpc

import (
    "context"
    "crypto/tls"
    "errors"
    "fmt"
    "net"
    "os"
    "os/signal"
    "syscall"
    "time"

    "google.golang.org/grpc"
    "google.golang.org/grpc/credentials"
    "google.golang.org/grpc/reflection"

    "github.com/jvdiamondtech/ms-identity-cat/cmd"
    "github.com/jvdiamondtech/ms-identity-cat/internal/adapter/inbound/grpc/interceptor"
    "github.com/jvdiamondtech/ms-identity-cat/internal/adapter/inbound/grpc/server"
    "github.com/jvdiamondtech/ms-identity-cat/internal/di"
    "github.com/jvdiamondtech/ms-identity-cat/internal/domain/ports/outbound/infrastructure"
    "github.com/jvdiamondtech/ms-identity-cat/internal/infrastructure/cache/redis"
    "github.com/jvdiamondtech/ms-identity-cat/internal/infrastructure/config"
    "github.com/jvdiamondtech/ms-identity-cat/internal/infrastructure/database/mysql"
    "github.com/jvdiamondtech/ms-identity-cat/internal/infrastructure/tracing"
    "github.com/jvdiamondtech/ms-identity-cat/internal/pb/auth"
    "github.com/jvdiamondtech/ms-identity-cat/internal/pb/identity/v1"
    "github.com/spf13/cobra"
)

const (
    defaultGRPCPort     = 50051
    shutdownTimeout     = 5 * time.Second
)

var (
    grpcPort int
)

// services contains all services that need cleanup
type services struct {
    tracer       *tracing.TracingService
    db           *mysql.Database
    redisManager *redis.Manager
    grpcServer   *grpc.Server
    identityServer *server.IdentityServer
}

// Command creates and returns the gRPC subcommand
func Command() *cobra.Command {
    grpcCmd := &cobra.Command{
        Use:   "grpc",
        Short: "Start the gRPC server",
        Long:  "Start the gRPC server for internal microservice communication",
        Run:   runGRPCServer,
    }

    grpcCmd.Flags().IntVarP(&grpcPort, "port", "p", 0, "gRPC server port (default is from config)")

    return grpcCmd
}

func init() {
    cmd.AddCommand(Command())
}

// runGRPCServer starts the gRPC service
func runGRPCServer(_ *cobra.Command, _ []string) {
    cfg := cmd.GetConfig()
    logger := cmd.GetLogger()

    rootCtx, rootCancel := context.WithCancel(context.Background())
    defer rootCancel()

    // Initialize all services
    svc, err := initializeServices(rootCtx, cfg, logger)
    if err != nil {
        logger.FatalWithContext(
            rootCtx,
            "Failed to initialize services",
            logger.Error("err", err),
        )
    }
    defer svc.cleanup(rootCtx, logger)

    // Create TracingService instance and create tracing span
    tracingService := svc.identityServer.GetTracingService()
    ctx, rootSpan := tracingService.StartSpan(rootCtx, "GRPCService")
    defer tracingService.SpanEnd(rootSpan)

    // Determine server port
    serverPort := determineGRPCPort(grpcPort, cfg)

    // Create network listener
    listen, err := net.Listen("tcp", fmt.Sprintf(":%d", serverPort))
    if err != nil {
        logger.FatalWithContext(
            ctx,
            "Failed to listen on port",
            logger.Int("port", serverPort),
            logger.Error("err", err),
        )
    }

    // Start gRPC server in background
    go func() {
        logger.InfoWithContext(
            ctx,
            "Starting gRPC server",
            logger.Int("port", serverPort),
        )
        if serverErr := svc.grpcServer.Serve(listen); serverErr != nil {
            logger.FatalWithContext(
                ctx,
                "Failed to start gRPC server",
                logger.Error("err", serverErr),
            )
        }
    }()

    // Wait for interrupt signal to gracefully shutdown the server
    quit := make(chan os.Signal, 1)
    signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)
    <-quit

    logger.InfoWithContext(ctx, "Shutting down gRPC server...")
    tracingService.TraceEvent(rootSpan, "Shutting down gRPC server")

    // Graceful shutdown with timeout
    shutdownCtx, cancel := context.WithTimeout(ctx, shutdownTimeout)
    defer cancel()

    done := make(chan struct{})
    go func() {
        svc.grpcServer.GracefulStop()
        close(done)
    }()

    select {
    case <-done:
        logger.InfoWithContext(ctx, "gRPC server shutdown gracefully")
    case <-shutdownCtx.Done():
        if errors.Is(shutdownCtx.Err(), context.DeadlineExceeded) {
            logger.WarnWithContext(ctx, "gRPC server shutdown timeout exceeded, forcing stop")
            svc.grpcServer.Stop()
        }
    }

    tracingService.TraceEvent(rootSpan, "gRPC server exited gracefully")
    logger.InfoWithContext(ctx, "gRPC server exited")
}
```

### Phase 5: Build and Development Tools

#### Makefile Extension

```makefile
# Makefile (additions)

# gRPC related targets
.PHONY: proto-gen proto-clean grpc-build grpc-run grpc-test

# Generate Protocol Buffer code
proto-gen:
	@echo "Generating Protocol Buffer code..."
	protoc --go_out=. --go_opt=paths=source_relative \
		--go-grpc_out=. --go-grpc_opt=paths=source_relative \
		proto/identity/v1/*.proto
	protoc --go_out=. --go_opt=paths=source_relative \
		--go-grpc_out=. --go-grpc_opt=paths=source_relative \
		proto/identity/auth/*.proto

# Clean generated Protocol Buffer code
proto-clean:
	@echo "Cleaning generated Protocol Buffer code..."
	find internal/pb -name "*.pb.go" -delete

# Build gRPC service
grpc-build:
	@echo "Building gRPC service..."
	go build -o bin/grpc ./cmd/grpc

# Run gRPC service locally
grpc-run:
	@echo "Running gRPC service..."
	go run main.go grpc

# Test gRPC service
grpc-test:
	@echo "Testing gRPC service..."
	go test ./internal/adapter/inbound/grpc/...

# Install Protocol Buffer tools
install-proto-tools:
	@echo "Installing Protocol Buffer tools..."
	go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
	go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
	go install github.com/grpc-ecosystem/grpc-health-probe@latest
```
