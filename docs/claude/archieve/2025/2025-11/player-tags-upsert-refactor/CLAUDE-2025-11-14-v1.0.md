# PlayerTag Redis Lock Optimization - Consumer Level Deduplication

**Version**: v1.0  
**Date**: 2025-11-14  
**Author**: Claude Code Assistant  
**Type**: Performance Optimization - Consumer Architecture Refactor

## 問題背景

### 當前問題
PlayerTag關聯寫入時經常因為Redis鎖獲取失敗導致事件處理失敗，主要原因是：

1. **高並發衝突**: Consumer使用10個worker pool並行處理KDS events
2. **同Player競爭**: 多個worker可能同時處理同一player的tag更新事件
3. **鎖機制限制**: 當前Redis鎖參數設置不適合高並發場景

### 核心衝突點
```
KDS Events → 10 Workers Pool → 同時處理同一Player → Redis Lock競爭 → 失敗事件
```

## 治本方案：Consumer層面去重

### 解決思路
在Consumer層實作player-based事件分組，確保同一player的事件串行處理，從根源上避免鎖競爭。

## 技術方案設計

### 1. 當前架構分析

#### 現有處理流程
```
KDS Record → processBatch() → Worker Pool (10 goroutines) → processRecord() → eventEnqueueProcess()
```

#### 問題節點
- `processBatch()`中的Worker Pool並行處理導致同Player事件競爭
- Worker直接處理record，沒有player維度的去重機制

### 2. 新架構設計

#### 核心改進：Player-Based Grouping
```
KDS Records → extractPlayerEvents() → groupByPlayer() → serializedProcessing() → Worker Pool
```

#### 關鍵組件

**PlayerEventGroup** - 按Player分組的事件容器
```go

type PlayerEventRecord struct {
```

**檔案**: `internal/infrastructure/kds/player_grouping.go`

```go
package kds

import (
    "context"
    "sync"
    "time"
    "encoding/json"
    
    "github.com/jvdiamondtech/ms-identity-cat/internal/domain/event"
    "github.com/jvdiamondtech/ms-identity-cat/internal/infrastructure/kds/types"
)

// PlayerEventRecord 包裝的Player事件記錄
type PlayerEventRecord struct {
    OriginalRecord types.Record    `json:"original_record"`
    EventType      string          `json:"event_type"`
    SequenceNumber string          `json:"sequence_number"`
    GlobalPlayerID string          `json:"global_player_id"`
    Timestamp      time.Time       `json:"timestamp"`
    EventData      json.RawMessage `json:"event_data"`
}

// PlayerEventGroup Player事件分組
type PlayerEventGroup struct {
    GlobalPlayerID string              `json:"global_player_id"`
    Events         []PlayerEventRecord `json:"events"`
    FirstEventTime time.Time           `json:"first_event_time"`
    LastEventTime  time.Time           `json:"last_event_time"`
    ProcessedAt    *time.Time          `json:"processed_at,omitempty"`
    TotalEvents    int                 `json:"total_events"`
}

// PlayerGroupProcessor Player分組處理器
type PlayerGroupProcessor struct {
    playerGroups    map[string]*PlayerEventGroup
    mutex           sync.RWMutex
    maxGroupAge     time.Duration
    maxGroupSize    int
    cleanupInterval time.Duration
    logger          ports.Logger
    ctx             context.Context
    cancel          context.CancelFunc
}

// NewPlayerGroupProcessor 創建Player分組處理器
func NewPlayerGroupProcessor(logger ports.Logger) *PlayerGroupProcessor {
    ctx, cancel := context.WithCancel(context.Background())
    
    processor := &PlayerGroupProcessor{
        playerGroups:    make(map[string]*PlayerEventGroup),
        maxGroupAge:     30 * time.Second,  // 最大分組存活時間
        maxGroupSize:    50,                // 最大分組事件數
        cleanupInterval: 10 * time.Second,  // 清理間隔
        logger:          logger,
        ctx:             ctx,
        cancel:          cancel,
    }
    
    // 啟動後台清理goroutine
    go processor.periodicCleanup()
    
    return processor
}

// AddEvent 添加事件到對應Player分組
func (pgp *PlayerGroupProcessor) AddEvent(record PlayerEventRecord) {
    pgp.mutex.Lock()
    defer pgp.mutex.Unlock()
    
    playerID := record.GlobalPlayerID
    group, exists := pgp.playerGroups[playerID]
    
    if !exists {
        // 創建新分組
        group = &PlayerEventGroup{
            GlobalPlayerID: playerID,
            Events:         make([]PlayerEventRecord, 0, 10),
            FirstEventTime: record.Timestamp,
            LastEventTime:  record.Timestamp,
            TotalEvents:    0,
        }
        pgp.playerGroups[playerID] = group
        
        pgp.logger.InfoLog("Created new player event group",
            pgp.logger.String("global_player_id", playerID),
        )
    }
    
    // 添加事件到分組
    group.Events = append(group.Events, record)
    group.LastEventTime = record.Timestamp
    group.TotalEvents++
    
    pgp.logger.DebugLog("Added event to player group",
        pgp.logger.String("global_player_id", playerID),
        pgp.logger.String("event_type", record.EventType),
        pgp.logger.String("sequence_number", record.SequenceNumber),
        pgp.logger.Int("total_events", group.TotalEvents),
    )
}

// GetReadyGroups 獲取準備處理的Player分組
func (pgp *PlayerGroupProcessor) GetReadyGroups() []*PlayerEventGroup {
    pgp.mutex.Lock()
    defer pgp.mutex.Unlock()
    
    var readyGroups []*PlayerEventGroup
    now := time.Now()
    
    for playerID, group := range pgp.playerGroups {
        // 分組準備條件：
        // 1. 達到最大事件數量
        // 2. 超過最大存活時間
        // 3. 已經被標記為處理中但超時
        
        shouldProcess := group.TotalEvents >= pgp.maxGroupSize ||
                        now.Sub(group.FirstEventTime) >= pgp.maxGroupAge ||
                        (group.ProcessedAt != nil && now.Sub(*group.ProcessedAt) > time.Minute)
        
        if shouldProcess && group.ProcessedAt == nil {
            // 標記為處理中
            processTime := now
            group.ProcessedAt = &processTime
            readyGroups = append(readyGroups, group)
            
            pgp.logger.InfoLog("Player group ready for processing",
                pgp.logger.String("global_player_id", playerID),
                pgp.logger.Int("total_events", group.TotalEvents),
                pgp.logger.Duration("age", now.Sub(group.FirstEventTime)),
            )
        }
    }
    
    return readyGroups
}

// RemoveGroup 移除已處理的Player分組
func (pgp *PlayerGroupProcessor) RemoveGroup(playerID string) {
    pgp.mutex.Lock()
    defer pgp.mutex.Unlock()
    
    if group, exists := pgp.playerGroups[playerID]; exists {
        pgp.logger.InfoLog("Removing processed player group",
            pgp.logger.String("global_player_id", playerID),
            pgp.logger.Int("total_events", group.TotalEvents),
        )
        delete(pgp.playerGroups, playerID)
    }
}

// periodicCleanup 定期清理過期分組
func (pgp *PlayerGroupProcessor) periodicCleanup() {
    ticker := time.NewTicker(pgp.cleanupInterval)
    defer ticker.Stop()
    
    for {
        select {
        case <-pgp.ctx.Done():
            return
        case <-ticker.C:
            pgp.cleanupExpiredGroups()
        }
    }
}

// cleanupExpiredGroups 清理過期分組
func (pgp *PlayerGroupProcessor) cleanupExpiredGroups() {
    pgp.mutex.Lock()
    defer pgp.mutex.Unlock()
    
    now := time.Now()
    expiredPlayerIDs := make([]string, 0)
    
    for playerID, group := range pgp.playerGroups {
        // 清理條件：已處理且超過5分鐘，或未處理但超過1小時
        shouldCleanup := (group.ProcessedAt != nil && now.Sub(*group.ProcessedAt) > 5*time.Minute) ||
                        (group.ProcessedAt == nil && now.Sub(group.FirstEventTime) > time.Hour)
        
        if shouldCleanup {
            expiredPlayerIDs = append(expiredPlayerIDs, playerID)
        }
    }
    
    for _, playerID := range expiredPlayerIDs {
        pgp.logger.InfoLog("Cleaning up expired player group",
            pgp.logger.String("global_player_id", playerID),
        )
        delete(pgp.playerGroups, playerID)
    }
    
    if len(expiredPlayerIDs) > 0 {
        pgp.logger.InfoLog("Cleanup completed",
            pgp.logger.Int("cleaned_groups", len(expiredPlayerIDs)),
            pgp.logger.Int("remaining_groups", len(pgp.playerGroups)),
        )
    }
}

// GetStats 獲取分組處理器統計信息
func (pgp *PlayerGroupProcessor) GetStats() map[string]interface{} {
    pgp.mutex.RLock()
    defer pgp.mutex.RUnlock()
    
    totalEvents := 0
    processedGroups := 0
    
    for _, group := range pgp.playerGroups {
        totalEvents += group.TotalEvents
        if group.ProcessedAt != nil {
            processedGroups++
        }
    }
    
    return map[string]interface{}{
        "total_groups":     len(pgp.playerGroups),
        "processed_groups": processedGroups,
        "pending_groups":   len(pgp.playerGroups) - processedGroups,
        "total_events":     totalEvents,
    }
}

// Shutdown 關閉分組處理器
func (pgp *PlayerGroupProcessor) Shutdown() {
    pgp.cancel()
    pgp.logger.InfoLog("Player group processor shutdown completed")
}
```

```go
package kds

import (
    "encoding/json"
    "fmt"
    "time"
    
    "github.com/jvdiamondtech/ms-identity-cat/internal/domain/event"
    "github.com/jvdiamondtech/ms-identity-cat/internal/infrastructure/kds/types"
)

// EventAnalyzer 事件分析器
type EventAnalyzer struct{}

// NewEventAnalyzer 創建事件分析器
func NewEventAnalyzer() *EventAnalyzer {
    return &EventAnalyzer{}
}

// ExtractPlayerID 從KDS Record中提取GlobalPlayerID
func (ea *EventAnalyzer) ExtractPlayerID(record types.Record) (string, error) {
    // 解析CloudEvent
    var cloudEvent event.CloudEvent
    if err := json.Unmarshal(record.Data, &cloudEvent); err != nil {
        return "", fmt.Errorf("failed to unmarshal cloud event: %w", err)
    }
    
    // 根據事件類型提取PlayerID
    switch cloudEvent.Type {
    case "identity.player.sync":
        return ea.extractPlayerIDFromPlayerSync(&cloudEvent)
    case "identity.tag.sync":
        return ea.extractPlayerIDFromTagSync(&cloudEvent)
    case "identity.level.sync":
        return ea.extractPlayerIDFromLevelSync(&cloudEvent)
    default:
        return "", nil // 非Player相關事件
    }
}

// extractPlayerIDFromPlayerSync 從PlayerSync事件提取PlayerID
func (ea *EventAnalyzer) extractPlayerIDFromPlayerSync(cloudEvent *event.CloudEvent) (string, error) {
    dataBytes, err := json.Marshal(cloudEvent.Data)
    if err != nil {
        return "", fmt.Errorf("failed to marshal event data: %w", err)
    }
    
    var playerSyncEvent event.PlayerSyncEvent
    if err := json.Unmarshal(dataBytes, &playerSyncEvent); err != nil {
        return "", fmt.Errorf("failed to unmarshal player sync event: %w", err)
    }
    
    return playerSyncEvent.Player.GlobalPlayerID, nil
}

// extractPlayerIDFromTagSync 從TagSync事件提取PlayerID（如果是PlayerTag相關）
func (ea *EventAnalyzer) extractPlayerIDFromTagSync(cloudEvent *event.CloudEvent) (string, error) {
    dataBytes, err := json.Marshal(cloudEvent.Data)
    if err != nil {
        return "", fmt.Errorf("failed to marshal event data: %w", err)
    }
    
    var tagSyncEvent event.TagSyncEvent
    if err := json.Unmarshal(dataBytes, &tagSyncEvent); err != nil {
        return "", fmt.Errorf("failed to unmarshal tag sync event: %w", err)
    }
    
    // TagSync事件可能不包含PlayerID，返回空字符串表示非Player相關
    return tagSyncEvent.GlobalPlayerID, nil
}

// extractPlayerIDFromLevelSync 從LevelSync事件提取PlayerID
func (ea *EventAnalyzer) extractPlayerIDFromLevelSync(cloudEvent *event.CloudEvent) (string, error) {
    dataBytes, err := json.Marshal(cloudEvent.Data)
    if err != nil {
        return "", fmt.Errorf("failed to marshal event data: %w", err)
    }
    
    var levelSyncEvent event.LevelSyncEvent
    if err := json.Unmarshal(dataBytes, &levelSyncEvent); err != nil {
        return "", fmt.Errorf("failed to unmarshal level sync event: %w", err)
    }
    
    return levelSyncEvent.GlobalPlayerID, nil
}

// IsPlayerRelatedEvent 判斷是否為Player相關事件
func (ea *EventAnalyzer) IsPlayerRelatedEvent(eventType string) bool {
    playerRelatedEvents := []string{
        "identity.player.sync",
        "identity.tag.sync",      // 可能包含PlayerTags
        "identity.level.sync",    // Player等級變更
    }
    
    for _, relatedType := range playerRelatedEvents {
        if eventType == relatedType {
            return true
        }
    }
    
    return false
}

// CreatePlayerEventRecord 創建Player事件記錄
func (ea *EventAnalyzer) CreatePlayerEventRecord(
    record types.Record,
    globalPlayerID string,
) (PlayerEventRecord, error) {
    // 解析事件基本信息
    var cloudEvent event.CloudEvent
    if err := json.Unmarshal(record.Data, &cloudEvent); err != nil {
        return PlayerEventRecord{}, fmt.Errorf("failed to unmarshal cloud event: %w", err)
    }
    
    return PlayerEventRecord{
        OriginalRecord: record,
        EventType:      cloudEvent.Type,
        SequenceNumber: record.SequenceNumber,
        GlobalPlayerID: globalPlayerID,
        Timestamp:      time.Now(), // 或從record中解析
        EventData:      record.Data,
    }, nil
}
```

```go
// 在KDSService結構體中添加新欄位
type KDSService struct {
    // ... 現有欄位 ...
    playerGroupProcessor *PlayerGroupProcessor
    eventAnalyzer        *EventAnalyzer
    groupProcessTicker   *time.Ticker
}

// 在NewKDSService中初始化
func NewKDSService(
    config *config.Config,
    logger ports.Logger,
    tracing ports.TracingService,
    queueService ports.QueueService,
    redisManager ports.RedisManager,
) ports.KDSService {
    ctx, cancel := context.WithCancel(context.Background())
    
    service := &KDSService{
        // ... 現有初始化 ...
        playerGroupProcessor: NewPlayerGroupProcessor(logger),
        eventAnalyzer:        NewEventAnalyzer(),
        ctx:                  ctx,
        cancel:               cancel,
    }
    
    // 啟動Player分組處理定時器
    service.startPlayerGroupProcessing()
    
    return service

// startPlayerGroupProcessing 啟動Player分組處理
func (k *KDSService) startPlayerGroupProcessing() {
    k.groupProcessTicker = time.NewTicker(5 * time.Second) // 每5秒處理一次
    
    go func() {
        for {
            select {
            case <-k.ctx.Done():
                return
            case <-k.groupProcessTicker.C:
                k.processPlayerGroups()
            }
        }
    }()
}

// processPlayerGroups 處理準備好的Player分組
func (k *KDSService) processPlayerGroups() {
    readyGroups := k.playerGroupProcessor.GetReadyGroups()
    
    if len(readyGroups) == 0 {
        return
    }
    
    k.logger.InfoLog("Processing player groups",
        k.logger.Int("ready_groups", len(readyGroups)),
    )
    
    // 使用現有的Worker Pool處理分組
    var wg sync.WaitGroup
    workerChan := make(chan *PlayerEventGroup, len(readyGroups))
    
    // 啟動workers處理Player分組
    numWorkers := k.config.Consumer.WorkerPoolSize
    if len(readyGroups) < numWorkers {
        numWorkers = len(readyGroups)
    }
    
    for i := 0; i < numWorkers; i++ {
        wg.Add(1)
        go func(workerID int) {
            defer wg.Done()
            for group := range workerChan {
                k.processPlayerGroup(group, workerID)
            }
        }(i)
    }
    
    // 分發Player分組到workers
    go func() {
        for _, group := range readyGroups {
            workerChan <- group
        }
        close(workerChan)
    }()
    
    wg.Wait()
    
    k.logger.InfoLog("Player groups processing completed",
        k.logger.Int("processed_groups", len(readyGroups)),
    )
}

// processPlayerGroup 處理單個Player事件分組
func (k *KDSService) processPlayerGroup(group *PlayerEventGroup, workerID int) {
    ctx := context.WithValue(k.ctx, "worker_id", workerID)
    
    k.logger.InfoLog("Worker processing player group",
        k.logger.Int("worker_id", workerID),
        k.logger.String("global_player_id", group.GlobalPlayerID),
        k.logger.Int("total_events", group.TotalEvents),
    )
    
    // 按時間序列順序處理事件（確保事件順序）
    sort.Slice(group.Events, func(i, j int) bool {
        return group.Events[i].Timestamp.Before(group.Events[j].Timestamp)
    })
    
    // 串行處理同一Player的所有事件
    successCount := 0
    for _, eventRecord := range group.Events {
        result := k.processRecord(ctx, eventRecord.OriginalRecord, "player-grouped")
        if result.Success {
            successCount++
        } else {
            k.logger.ErrorLog("Failed to process event in player group",
                k.logger.String("global_player_id", group.GlobalPlayerID),
                k.logger.String("event_type", eventRecord.EventType),
                k.logger.String("sequence_number", eventRecord.SequenceNumber),
                k.logger.Error("error", result.Error),
            )
        }
    }
    
    // 記錄處理結果
    k.logger.InfoLog("Player group processing completed",
        k.logger.Int("worker_id", workerID),
        k.logger.String("global_player_id", group.GlobalPlayerID),
        k.logger.Int("total_events", group.TotalEvents),
        k.logger.Int("success_events", successCount),
        k.logger.Int("failed_events", group.TotalEvents-successCount),
    )
    
    // 清理已處理的分組
    k.playerGroupProcessor.RemoveGroup(group.GlobalPlayerID)
}
```

#### Step 2.2: 修改processBatch支援分組處理
在現有的`processBatch`方法中添加分組邏輯：

```go
// processBatch 批次處理記錄（修改版本）
func (k *KDSService) processBatch(ctx context.Context, batch RecordBatch) []ProcessResult {
    results := make([]ProcessResult, 0, len(batch.Records))
    
    // Step 1: 分離Player相關和非Player相關的事件
    playerEvents := make([]types.Record, 0)
    nonPlayerEvents := make([]types.Record, 0)
    
    for _, record := range batch.Records {
        // 提取事件類型
        var cloudEvent event.CloudEvent
        if err := json.Unmarshal(record.Data, &cloudEvent); err != nil {
            // 無法解析的事件直接處理
            nonPlayerEvents = append(nonPlayerEvents, record)
            continue
        }
        
        // 判斷是否為Player相關事件
        if k.eventAnalyzer.IsPlayerRelatedEvent(cloudEvent.Type) {
            playerEvents = append(playerEvents, record)
        } else {
            nonPlayerEvents = append(nonPlayerEvents, record)
        }
    }
    
    k.logger.InfoLog("Batch event classification",
        k.logger.Int("total_events", len(batch.Records)),
        k.logger.Int("player_events", len(playerEvents)),
        k.logger.Int("non_player_events", len(nonPlayerEvents)),
    )
    
    // Step 2: Player相關事件加入分組處理
    for _, record := range playerEvents {
        globalPlayerID, err := k.eventAnalyzer.ExtractPlayerID(record)
        if err != nil {
            k.logger.ErrorLog("Failed to extract player ID",
                k.logger.String("sequence_number", record.SequenceNumber),
                k.logger.Error("error", err),
            )
            // 提取失敗的事件直接處理
            nonPlayerEvents = append(nonPlayerEvents, record)
            continue
        }
        
        // 空PlayerID的事件直接處理
        if globalPlayerID == "" {
            nonPlayerEvents = append(nonPlayerEvents, record)
            continue
        }
        
        // 創建Player事件記錄並加入分組
        eventRecord, err := k.eventAnalyzer.CreatePlayerEventRecord(record, globalPlayerID)
        if err != nil {
            k.logger.ErrorLog("Failed to create player event record",
                k.logger.String("global_player_id", globalPlayerID),
                k.logger.String("sequence_number", record.SequenceNumber),
                k.logger.Error("error", err),
            )
            continue
        }
        
        k.playerGroupProcessor.AddEvent(eventRecord)
        
        // 添加成功結果（事件已加入分組處理）
        results = append(results, ProcessResult{
            EventID:        extractEventID(record),
            EventType:      eventRecord.EventType,
            SequenceNumber: record.SequenceNumber,
            Success:        true,
            Message:        "Added to player group for processing",
        })
    }
    
    // Step 3: 非Player事件使用原有邏輯並行處理
    if len(nonPlayerEvents) > 0 {
        nonPlayerResults := k.processNonPlayerEventsBatch(ctx, nonPlayerEvents, batch.ShardID)
        results = append(results, nonPlayerResults...)
    }
    
    return results
}

// processNonPlayerEventsBatch 處理非Player相關事件（原有邏輯）
func (k *KDSService) processNonPlayerEventsBatch(
    ctx context.Context,
    records []types.Record,
    shardID string,
) []ProcessResult {
    results := make([]ProcessResult, 0, len(records))
    resultChan := make(chan ProcessResult, len(records))
    
    var wg sync.WaitGroup
    workerChan := make(chan types.Record, k.config.Consumer.WorkerBufferSize)
    
    // 啟動workers
    numWorkers := k.config.Consumer.WorkerPoolSize
    if len(records) < numWorkers {
        numWorkers = len(records)
    }
    
    for i := 0; i < numWorkers; i++ {
        wg.Add(1)
        go func(workerID int) {
            defer wg.Done()
            for record := range workerChan {
                result := k.processRecord(ctx, record, shardID)
                resultChan <- result
            }
        }(i)
    }
    
    // 分發工作
    go func() {
        for _, record := range records {
            workerChan <- record
        }
        close(workerChan)
    }()
    
    // 收集結果
    go func() {
        wg.Wait()
        close(resultChan)
    }()
    
    for result := range resultChan {
        results = append(results, result)
    }
    
    return results
}
```

## 部署策略

### 階段性部署
1. **Phase 1**: 只啟用監控和日誌，不改變處理邏輯
2. **Phase 2**: 小流量測試（只對特定merchant啟用分組）
3. **Phase 3**: 全面啟用分組處理

### 回滾機制
通過配置開關`CONSUMER_PLAYER_GROUPING=false`快速回滾到原有處理邏輯。

## 預期效果

### 性能改善
- **Redis鎖競爭**: 同Player事件串行處理，徹底避免鎖競爭
- **事件失敗率**: 預期降低至<1%
- **處理吞吐量**: 分組批次處理提高整體效率

### 數據一致性
- **事件順序**: 確保同Player事件按時間順序處理
- **狀態一致**: 避免並發更新導致的數據不一致

### 系統穩定性
- **失敗率降低**: 消除Redis鎖失敗導致的事件處理失敗
- **資源使用**: 減少無效的重試和鎖等待時間

## 風險評估與緩解

### 潛在風險
1. **記憶體使用**: Player分組可能消耗額外記憶體
2. **處理延遲**: 分組等待可能增加個別事件的處理延遲
3. **複雜度**: 新增的分組邏輯增加系統複雜度

### 緩解措施
1. **記憶體管理**: 實作定期清理和大小限制
2. **延遲控制**: 配置合理的分組超時時間
3. **向後兼容**: 保留開關快速回滾到原有邏輯

## 總結

Consumer層面去重是解決PlayerTag Redis鎖競爭的治本方案。通過player-based事件分組，我們可以：

1. **根本解決**: 從源頭避免同Player事件的並發處理
2. **保證順序**: 確保同Player事件按正確順序處理
3. **提升效率**: 減少無效的鎖競爭和重試
4. **向後兼容**: 保留快速回滾能力

實施後預期Redis鎖失敗率將從當前水平降低至<1%，大幅提升系統穩定性和處理效率。
